# Raw data

Les données brutes sont immuables et ne sont jamais versionnées dans Git.

MaleCNS v1.0 doit être placé dans :

```text
data/raw/malecns/v1.0/
```

Utiliser `download_data.bat` pour télécharger, reprendre ou contrôler les trois
fichiers minimaux. Les fichiers dérivés doivent aller dans `data/derived/`, jamais
à côté des sources.
